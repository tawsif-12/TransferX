## ⚡ Quick Actions

| Action | Steps | Result |
|--------|-------|--------|
| **Add Player** | Players → Add Player → Fill Form → Submit | New player created |
| **Edit Player** | Players → Edit (✏️) → Update fields → Submit | Player updated |
| **Change Club** | Edit Player → Change "Current Club" → Submit | Club assignment updated |
| **Update Market Value** | Edit Player → Change "Market Value" → Submit | Value updated |
| **Delete Player** | Players → Delete (🗑️) → Confirm | Player removed |
| **View Profile** | Players → View (👁️) | See full history |
| **Search Players** | Players → Type name in search | Filter by name |
| **Filter Position** | Players → Select position dropdown | Filter by position |
| **Filter Club** | Players → Select club dropdown | Filter by club |

## 🔍 Filter & Search Combinations

**Scenario 1: Find all Barcelona forwards**
1. Type "Barcelona" in search → No, use club filter
2. Select "Barcelona" from club dropdown
3. Select "FORWARD" from position dropdown
4. Table shows only Barcelona forwards

**Scenario 2: Find player "Messi" and update market value**
1. Type "Messi" in search box
2. Table shows players named Messi
3. Click Edit (✏️)
4. Update Market Value field
5. Click "Update Player"

**Scenario 3: View all defenders**
1. Clear search box
2. Select "DEFENDER" from position dropdown
3. Table shows all defenders

## 💰 Market Value Updates

### When to Update Market Value:

**Increase Value:**
- ⬆️ Player scores important goals
- ⬆️ Player gets international call-up
- ⬆️ Young player showing promise
- ⬆️ Recovery from injury
- ⬆️ Winning matches/good performance

**Decrease Value:**
- ⬇️ Player has poor performance
- ⬇️ Long-term injury
- ⬇️ Player age increases (28+)
- ⬇️ Missing matches/not playing
- ⬇️ Losing form

### Example Updates:

```
Player: Neymar
Old Value: €120,000,000
New Value: €110,000,000
Reason: Hamstring injury (3 months)

---

Player: Vinior
Old Value: €50,000,000
New Value: €65,000,000  
Reason: 12 goals in last 10 games
```
